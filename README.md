# CFU Game Jam

Сайт Крымского геймджема КФУ: белый фон, бордово-золотая палитра и объёмный пиксельный интерфейс. Каталог и страницы игр, команды, дневники, профили и сообщения.

Живая версия: https://perrarancino.github.io/CFUjam/

## Как устроен репозиторий

- Корень репозитория — **готовая сборка**, которую отдаёт GitHub Pages (`index.html`, `assets/`, `img/`, `fonts/`, `pixel-icons/`, `credits.html`).
- Папка `app/` — **исходники** на React + Vite. Это источник правды: сайт собирается из неё.

## Разработка

```bash
cd app
npm ci
npm run dev -- --host 127.0.0.1 --port 8766 --strictPort
npm run build    # сборка в app/dist
npm run build:pages # сборка и копирование в корень для GitHub Pages
```

GitHub Pages публикует корень ветки `main`. Перед коммитом для публикации выполнить `npm run build:pages` из `app/`, затем закоммитить исходники и обновлённую сборку. Не редактировать готовую сборку вручную.

GitHub Pages размещает только статический фронтенд. Бэкенд из `server/` там не запускается; при его отсутствии доступны локальные демо-операции. Переписки сохраняются в текущем браузере и не доставляются другим участникам.

## Что внутри `app/src`

- `App.jsx`, `nav.jsx`, `store.jsx` — оболочка, маршруты вкладок (`#/games`) и состояние (данные в `localStorage`, прототип без сервера)
- `views/` — вкладки: главная, команды, игры, участники, кабинет, настройки, правила
- `modals.jsx` — вход и регистрация (ник + пароль, демо-вход VK и Google без сохранения), сообщения, заявки
- `legacy-ui12.js` — 3D-карусель и физика наведения; `legacy-ui14.js` — пиксельная волна между вкладками и подгонка шапки
- `cfu-theme.css` — актуальная тема, поверх legacy `styles.css`; правила дизайна в `app/DESIGN.md`
- `catalog.js`, `profiles.js`, `messages.js` — общие данные игр, профилей и локальных переписок
- `public/` — фото, шрифты, иконки, страница авторов
