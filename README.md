# CFU Game Jam

Сайт Крымского геймджема КФУ: ностальгический пиксельный стиль с вращающейся 3D-каруселью, командами, играми, участниками и кабинетом.

Живая версия: https://perrarancino.github.io/CFUjam/

Это статический прототип без сервера: регистрация, команды и голоса хранятся в `localStorage` браузера.

- `index.html` — весь сайт (HTML, CSS и JS в одном файле)
- `fonts/` — шрифты Handjet и DotGothic16 (SIL OFL 1.1)
- `img/` — временные фотографии (авторы и лицензии: `CREDITS.md`, `credits.html`)
- `icons-LICENSE.txt` — лицензия иконок Lucide
